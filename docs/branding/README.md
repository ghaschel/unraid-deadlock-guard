# Deadlock Guard branding

The **Switchpoint** mark represents one route connecting while the other stays disconnected. The product name remains **Deadlock Guard**; the tagline is **Stop first. Start next.**

- [Monochrome mark](../../icon.svg): the canonical geometry, also packaged for Unraid and used by Community Apps metadata.
- [Logo](logo.svg): the mark in **#FFDB58** beside the wordmark; transparent background with light/dark text variants selected by the viewer’s color scheme.
- [README header](header.svg): the logo and tagline on charcoal **#202020**.

Keep the mark’s proportions, rounded ends and gaps intact. Use the exact yellow **#FFDB58** for branded graphics. Inside Unraid, the mark uses a CSS mask and inherits the UI text color; it does not introduce a yellow accent into the settings or plugin list. The standalone SVG uses neutral gray so it remains visible when Community Apps displays it as an image on either background.

These SVGs are editable source assets, with no external fonts, scripts or image dependencies. They use the repository’s [MIT license](../../LICENSE).
